# PAVMO - Movie Portal

PAVMO is a movie and TV series portal website developed using HTML and CSS. This website is designed to provide users with a simple and organized platform to explore movie collections, TV series, and their favorite entertainment content.

## Features
- Movie collection - Browse a collection of movies.
- TV series collection - Explore available TV series.
- Genre categories - Discover movies based on genres.
- Watchlist section - View a collection of selected content.
- Login page - User login interface.

## Technologies
- HTML5
- CSS3
